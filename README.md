# chimikko-db-hub
A tiny character database and publishing hub for creators

## ホーム画面追加・共有サムネイル

Safariの共有メニューから「ホーム画面に追加」で、ちみHubアイコンから起動できます。Androidは対応ブラウザのインストール操作を使います。ホーム画面版で改めてGoogleログインが必要になる場合があります。

PWAはオンライン利用専用です。Service Workerは汎用の `offline.html` だけを保存し、投稿・画像・認証通信・アプリJSをCacheStorageに保存しません。通信失敗時はオフライン案内を表示します。編集中の強制更新はしません。ネット接続中に画面を開き直すとアプリ本体は再検証されます。オフライン案内自体を更新する場合は `sw.js` のキャッシュバージョンを増やしてください。

共通OGPは `og.png`。Netlify標準環境変数 `URL`（本番URL）からビルド時に絶対URLを設定します。明示する場合は `SITE_URL=https://独自ドメイン` を設定してください。ローカルビルドはlocalhostを使うため、そのまま手動アップロードする際は必ず `SITE_URL` を指定して再ビルドしてください。SNS側の既存プレビューキャッシュは即時更新されない場合があります。個別プロフィール画像のOGP生成は含みません。

公開後の実機確認：ホーム画面追加→起動→Googleログイン→保存→再起動、オフライン起動→案内→接続回復、LINE等へのURL貼り付け。自動テストは通信分岐・キャッシュ範囲・既存処理を確認しますが、実機のGoogle認証やSNSプレビュー取得そのものは手動確認が必要です。

OGP制作：内蔵画像生成。指示は「クリーム・焦げ茶・はちみつ色の手作りカード、見出し『ちみっこHub』、副題『小さな創作者プロフィール掲示板』、本・プロフィールカード・きらめき」。アプリアイコンは既存ブランドのLucide sparklesを利用（`icons/LICENSE.txt`）。

## 小型WebP投稿版

実装上の参加枠は運営1名＋参加者5名の合計6名です。Googleログイン、プロフィール・代表キャラ3名・世界観メモ、最大4枚の小型WebP投稿、公開／非公開、投稿削除に対応しています。

接続前はデモ表示のままです。[接続・運用手順](SETUP.md)に従ってFirebaseのWeb設定、Firestore Rules、インデックス除外、運営者の参加枠を設定してください。Cloud Storage・Blazeは使いません。

Netlifyは `npm run build` で静的ファイルとiOS向けWebP変換Worker・WASMを `dist` へ出力します。テストツールやFirestoreルールを公開ディレクトリに含めません。画像変換は端末内で実行します。

利用規約・プライバシーポリシー・コンテンツガイドラインはログイン不要で閲覧できます。Googleログインは3文書への同意チェック後に開始し、問い合わせ・削除依頼は公開のGoogleフォームで受け付けます。

検証：`npm test`（画像処理）、`npm run test:rules`（Firestoreエミュレーター）。本番Firebaseと実ブラウザでのログイン・画像表示の確認は別途必要です。

## 起動・画像取得の復旧

Firebase SDKは固定済みnpmパッケージから `dist/firebase-sdk.js` にビルドします。ソースHTMLの直接公開ではなく `npm run build` の出力を公開してください。外部アイコンとフォントはアプリの起動をブロックしません。
画像と詳細プロフィールの一時的な通信失敗は最大2回再試行し、権限拒否・削除済み・不正データは自動再試行しません。失敗時は手動再読み込みが可能です。公開一覧はアプリの認証コールバックを待たず購読を開始しますが、Firebase内部の認証準備や回線自体の待ちは残ります。
Firestoreルール、保存データ、参加枠、永続キャッシュ設定、長時間ポーリング設定は変更していません。実機の速度改善幅は未計測です。
